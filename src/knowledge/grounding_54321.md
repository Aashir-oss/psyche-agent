TITLE: 5-4-3-2-1 Grounding
WHEN_TO_USE: During acute anxiety, panic, or when thoughts spiral and you feel disconnected from the present moment.
STEPS:
- Name 5 things you can SEE right now (say them out loud if possible).
- Name 4 things you can TOUCH (feel the chair, your clothes, the floor).
- Name 3 things you can HEAR.
- Name 2 things you can SMELL.
- Name 1 thing you can TASTE.
- Breathe slowly between each step. Repeat the cycle if anxiety is still high.
SOURCE: Standard clinical grounding technique; described in Najavits, L. M. — Seeking Safety (book; grounding chapter). Original summary written for this project.
