TITLE: Structured Problem Solving
WHEN_TO_USE: When a practical problem (money, studies, conflict) feeds anxiety because it feels huge and undefined.
STEPS:
- Define the problem in one concrete sentence. Vague → specific ("I will fail" → "I have 3 chapters left and 4 days").
- Brainstorm at least 5 possible solutions — quantity first, no judging yet.
- For each, list one pro and one con honestly.
- Pick the solution with the best pro/con balance that you can start TODAY.
- Break it into the smallest possible first step and schedule it.
- Review in one week: did it help? Adjust or pick the next-best option.
